# Scare Cue: the props

Guests arrive at eight. Each prop reads its rules from the top, and the first true rule is the one that runs.

## The jump-scare

WHEN a visitor is near, THE jump-scare SHALL trigger.

## The fog machine

WHEN a visitor is near, THE fog machine SHALL spray fog.
THE fog machine SHALL stop the fog.

## The exit light

WHEN the fog is on, THE exit light SHALL turn off.
THE exit light SHALL stay on.
